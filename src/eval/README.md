# src/eval/
Evaluation and inference scripts for model conditions.

| File | Purpose |
|------|---------|
| few_shot_eval.py | Few-shot prompting evaluation |
| prompt_compare.py | Prompt variant comparison |
| run_eval_new_conditions.py | Eval new model conditions |
| run_inference_all_conditions.py | Inference for all A-E conditions |
| run_llm_judge.py | LLM judge scoring |
